  <action>
**1. Kompilacja i flash firmware:**
```bash
arduino-cli compile --fqbn arduino:renesas_uno:unor4wifi src/arduino/aries_controller/
arduino-cli upload  --fqbn arduino:renesas_uno:unor4wifi --port /dev/ttyACM0 src/arduino/aries_controller/
```

**2. Weryfikacja startu — Serial Monitor:**
Odczekac 3 sekundy po flash, otworzyc Serial:
```bash
stty -F /dev/ttyACM0 115200 raw -echo
timeout 5 cat /dev/ttyACM0
```
Oczekiwany output: linie `[RTC]`, `[SD]` lub `SD fail` / `RTC: FAIL` (zaleznie od dostepnosci hardware). Brak crash, brak watchdog reset.

**3. Weryfikacja komendy diagnostycznej 'D':**
Wyslac bajt 'D' na Serial i odczytac odpowiedz:
```python
python3 -c "
import serial, time
ser = serial.Serial('/dev/ttyACM0', 115200, timeout=2)
time.sleep(2)
ser.write(b'D')
time.sleep(0.5)
odp = ser.read(ser.in_waiting).decode('ascii', errors='replace')
print(odp)
ser.close()
"
```
Oczekiwany output: `[DUMP] Ostatnie 10 wpisow DataLogger:` ... `[DUMP] Koniec.`

Jesli karta SD niedostepna, bufor bedzie pusty ale naglowek DUMP powinien sie pojawic.
