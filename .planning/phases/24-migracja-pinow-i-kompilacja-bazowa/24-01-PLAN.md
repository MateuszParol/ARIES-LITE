**2b. pinMode dla pinow analogowych LCD — per D-11:**
W setup(), zaraz po `Serial.begin(115200);`, dodaj jawne ustawienie trybu wyjsciowego dla A0 i A1:
```cpp
    Serial.begin(115200);

    // Jawny pinMode dla pinow analogowych LCD (RS=A0, E=A1) — per D-11

    pinMode(A1, OUTPUT);
```
UWAGA: Te dwa wywolania musza znalezc sie w setup() przed `hmi.inicjalizuj()` — LiquidCrystal inicjalizuje piny LCD w konstruktorze/begin(), jawny pinMode gwarantuje stan OUTPUT zanim HMI przejmie sterowanie.

**3. Zamiana dtostrf() na snprintf() (MIG-06, D-07):**

```cpp
char pan_buf[5], tilt_buf[5];

// PO:
char pan_buf[5], tilt_buf[5];
snprintf(pan_buf,  sizeof(pan_buf),  "%4d", (int)kat_pan);
snprintf(tilt_buf, sizeof(tilt_buf), "%4d", (int)kat_tilt);
```
Takze zaktualizuj komentarz nad lcd_krok() — usun wzmiankę o dtostrf, dodaj "snprintf z int cast".

**4. Serial CDC wait — skroc do 500ms (MIG-07 firmware, D-06):**
W setup() zmien:
```cpp
// PRZED:
// Leonardo USB CDC — czekaj az host otworzy port, max 3 sekundy
// (bez timeoutu Leonardo zawiesza sie na while(!Serial))
uint32_t start = millis();
while (!Serial && millis() - start < 3000) {
    delay(10);
}

// PO:
// R4 WiFi: USB przez ESP32-S3 bridge — max 500ms wait
// (zachowac timeout — nie blokujacy, dziala na obu platformach)
uint32_t start = millis();
while (!Serial && millis() - start < 500) {
    delay(10);
}
```

**5. Soft Start delay(500) (MIG-08, D-05):**
W setup() dodaj `delay(500);` z komentarzem BEZPOSREDNIO PRZED `serwa.inicjalizuj();`:
```cpp
    // Inicjalizacja HMI: LCD bootscreen + piny buzzer/przycisk
    hmi.inicjalizuj();

    // Soft Start 500ms — stabilizacja napiecia zasilacza 6V PRZED ruchem serw (MIG-08, D-05)
    delay(500);

    // Inicjalizacja serw: attach + bezpieczny start (rampa 1000ms) + parametry PID
    serwa.inicjalizuj();
```
UWAGA: delay(500) musi byc PO hmi.inicjalizuj() (zeby bootscreen pojawil sie od razu) ale PRZED serwa.inicjalizuj() (zeby zasilacz ustabilizowal sie przed ruchem serw).

**6. Bootscreen wersja (D-12):**
W `HMI::lcd_bootscreen()` zmien:
```cpp
_lcd.print("ARIES-LITE v2.1");
```
