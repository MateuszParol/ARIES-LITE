Zmienne globalne:
```cpp
uint8_t ramka_buf[FRAME_SIZE];
uint8_t ramka_idx = 0;
StanParsera stan_parsera = WAIT_START;
```

Funkcja `przetwarzaj_bajt(uint8_t bajt)`:
- `switch (stan_parsera)`:
  - `WAIT_START`: jesli `bajt == START_MARKER` -> `ramka_buf[0] = bajt`, `ramka_idx = 1`, `stan_parsera = READ_PAYLOAD`. Inny bajt: cichy drop (D-03).
  - `READ_PAYLOAD`: `ramka_buf[ramka_idx++] = bajt`. Jesli `ramka_idx == FRAME_SIZE`: oblicz checksum XOR bajtow 1-6 (`uint8_t obliczona = 0; for (uint8_t i = 1; i <= 6; i++) obliczona ^= ramka_buf[i];`). Jesli `obliczona == ramka_buf[7]`: `Serial.write(ramka_buf, FRAME_SIZE);` (echo per D-02). Bledna checksum: cichy drop per D-03. W obu: `ramka_idx = 0; stan_parsera = WAIT_START;`.
  - `default`: resync — `ramka_idx = 0; stan_parsera = WAIT_START;`.

Zmodyfikuj `setup()`:
```cpp
void setup() {
    Serial.begin(115200);
    // Leonardo USB CDC — czekaj z timeoutem 3s
    uint32_t start = millis();
    while (!Serial && millis() - start < 3000) { delay(10); }
}
```

Zmodyfikuj `loop()`:
```cpp
void loop() {
    while (Serial.available() > 0) {
        uint8_t bajt = (uint8_t)Serial.read();
        przetwarzaj_bajt(bajt);
    }
}
```
