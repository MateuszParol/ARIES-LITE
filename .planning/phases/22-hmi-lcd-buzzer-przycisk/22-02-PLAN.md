Pelna funkcja przejdz_do() po zmianie:

```cpp
void przejdz_do(StanSystemu nowy_stan) {
    stan_systemu = nowy_stan;
    if (nowy_stan == SCAN) {
        czas_startowy_skanu = millis();
        pidPan.Reset();
        pidTilt.Reset();
    } else if (nowy_stan == TRACK) {
        tone(BUZZER_PIN, 1000, 100);  // 1kHz, 100ms — "Target Lock" (HMI-02)
        pidPan.Reset();
        pidTilt.Reset();
    }
    // IDLE: nic dodatkowego
}
```

**4. Nowa funkcja przycisk_tick() (po lcd_tick(), przed setup()):**

```cpp
// Obsluga przycisku abort — debounce millis() (D-08)
// Aktywny TYLKO w trybie TRACK — przerywa sledzenie → SCAN (D-07, HMI-03)
// INPUT_PULLUP: LOW = wcisniety, HIGH = nie wcisniety (Pitfall 6)
void przycisk_tick() {
    if (stan_systemu != TRACK) return;  // D-07: ignoruj poza TRACK

    bool aktualny = digitalRead(PRZYCISK_PIN);
    if (aktualny != przycisk_ostatni_stan) {
        przycisk_czas_zmiany = millis();
    }
    // Zbocze stabilne przez DEBOUNCE_MS i przycisk wcisniety (LOW)
    if ((millis() - przycisk_czas_zmiany >= DEBOUNCE_MS) &&
        aktualny == LOW && przycisk_ostatni_stan == HIGH) {
        przejdz_do(SCAN);  // Abort TRACK → SCAN
    }
    przycisk_ostatni_stan = aktualny;
}
```

UWAGA do implementacji przycisk_tick(): Stan `przycisk_ostatni_stan` musi byc aktualizowany NA KONCU funkcji (po sprawdzeniu warunku), nie na poczatku. Inaczej zbocze HIGH→LOW nigdy nie zostanie wykryte, bo `przycisk_ostatni_stan` zostanie nadpisany PRZED porownaniem. Wzorzec z RESEARCH.md Pattern 2 aktualizuje stan na poczatku — to jest inne podejscie (edge detect vs level detect). Powyzszy wzorzec wykrywa zbocze opadajace z debounce.
