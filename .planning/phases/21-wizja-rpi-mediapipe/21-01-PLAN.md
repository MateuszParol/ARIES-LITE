Klasa `KameraRPi`:
- `__init__(self, szerokosc: int = LORES_WIDTH, wysokosc: int = LORES_HEIGHT) -> None` — przechowuje parametry, `self._picam2 = None`, `self._klatka = None`, `self._lock = threading.Lock()`, `self._running = False`, `self._format_zweryfikowany = False`
- `start(self) -> None` — tworzy Picamera2, konfiguruje lores YUV420 z `create_video_configuration(lores={"size": (szerokosc, wysokosc), "format": "YUV420"}, controls={"ColourGains": AWB_FALLBACK_GAINS})`. Potem `picam2.start()`, `time.sleep(AWB_WARMUP_DELAY)`, `capture_metadata()` do odczytu gains, `set_controls({"ColourGains": (float(r), float(b))})` — per D-04 dwuetapowy AWB. Fallback na AWB_FALLBACK_GAINS jesli metadata zwroci None lub (0.0, 0.0). Loguj `ColourGains zablokowane: (R=..., B=...)`. Po AWB: uruchom daemon thread `_petla_przechwytywania`.
- `_petla_przechwytywania(self) -> None` — daemon thread: while self._running: `capture_array("lores")`, loguj shape raz (`_format_zweryfikowany`), konwersja YUV→BGR: najpierw probuj `cv2.COLOR_YUV2BGR_NV12`, fallback `cv2.COLOR_YUV420p2BGR` (per Research: Bookworm moze zwracac NV12). Pod lockiem zapisz do `self._klatka`. Sleep(0.001) na koncu iteracji. try/except z logging.error na calej petli.
- `odczytaj(self) -> Optional[np.ndarray]` — pod lockiem kopiuj i zwroc `self._klatka` (lub None jesli brak).
- `zatrzymaj(self) -> None` — `self._running = False`, czekaj na watek (join z timeout=2.0), `picam2.stop()`, `picam2.close()`, loguj "Kamera zatrzymana".

Import Picamera2 z try/except jak w legacy — jezeli ImportError: `logger.error(...)` i `sys.exit(1)`.

Stale modulowe:
- `MODEL_PATH = "models/blaze_face_short_range.tflite"`
- `MIN_CONFIDENCE = 0.5`
- `STICKY_PROG = 0.20` (20% histereza — per D-06 Research recommendation)

Klasa `WykrywaczTwarzy`:
- `__init__(self, model_path: str = MODEL_PATH, min_confidence: float = MIN_CONFIDENCE) -> None` — tworzy `mp.tasks.vision.FaceDetector` z `FaceDetectorOptions(base_options=mp_python.BaseOptions(model_asset_path=model_path), running_mode=mp_vision.RunningMode.VIDEO, min_detection_confidence=min_confidence)`. Przechowuje `self._detektor`. Inicjalizuj `self._sticky_bbox: Optional[Tuple[int, int, int, int]] = None`. Loguj "MediaPipe FaceDetector zaladowany: {model_path}".

- `wykryj(self, klatka_bgr: np.ndarray, timestamp_ms: int) -> List[Tuple[int, int, int, int]]` — konwertuje BGR→RGB przez `cv2.cvtColor(klatka_bgr, cv2.COLOR_BGR2RGB)`, tworzy `mp.Image(image_format=mp.ImageFormat.SRGB, data=klatka_rgb)`, wywoluje `self._detektor.detect_for_video(mp_image, timestamp_ms)`. Iteruje `wynik.detections` i buduje liste `(bb.origin_x, bb.origin_y, bb.width, bb.height)` — pikselowe wspolrzedne (Tasks API, NIE normalizowane). Zwraca liste bbox. try/except na detect_for_video — log error, zwroc pusta liste.

- `wybierz_twarz(self, twarze: List[Tuple[int, int, int, int]]) -> Optional[Tuple[int, int, int, int]]` — sticky tracking per D-06 i Research Pattern 3. Jezeli brak twarzy: `self._sticky_bbox = None`, zwroc None. Oblicz area kazdej twarzy (`w * h`). Znajdz idx_max (najwiekszy area). Jezeli `self._sticky_bbox is None` — ustaw i zwroc natychmiast. Jezeli jest sticky: oblicz area_sticky vs area_max. Przeskocz na nowy cel TYLKO jesli `area_max > area_sticky * (1.0 + STICKY_PROG)`. Inaczej: szukaj sticky_bbox wsrod aktualnych twarzy (najblizszy do poprzedniego srodka — overlap check lub IOU), update wspolrzedne. Jezeli sticky zniknal z kadru — trzymaj ostatnia pozycje przez 1-2 iteracje, potem resetuj. Loguj `logger.debug(f"Sticky switch: ...")` przy zmianie celu.

- `zamknij(self) -> None` — `self._detektor.close()`. Loguj "MediaPipe FaceDetector zamkniety".
