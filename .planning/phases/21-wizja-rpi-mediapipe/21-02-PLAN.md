Stale modulowe:
- `HEARTBEAT_INTERVAL = 0.200` (200ms per D-07)
- `HEARTBEAT_POLL = 0.050` (50ms poll w watku heartbeat)
- `MODE_IDLE = 0`
- `MODE_SCAN = 1`
- `MODE_TRACK = 2`

Klasa `WatekHeartbeat(threading.Thread)`:
- `__init__(self, serial_iface: SerialInterface, czas_ostatniej_tx_ref: list) -> None` — daemon=True, name="heartbeat". `self._serial = serial_iface`, `self._czas_ref = czas_ostatniej_tx_ref` (lista [float] — mutowalny ref), `self._stop_event = threading.Event()`.
- `stop(self) -> None` — `self._stop_event.set()`.
- `run(self) -> None` — while not stop_event: sprawdz `time.time() - self._czas_ref[0] >= HEARTBEAT_INTERVAL`. Jezeli tak: `self._serial.send_frame(mode=MODE_SCAN, error_x=0, error_y=0, face_size=0)`, update `self._czas_ref[0]`. try/except na send_frame — log error, nie przerywaj. Sleep(HEARTBEAT_POLL).

Klasa `MozgRPi`:
- `__init__(self, port: str = "/dev/ttyACM0") -> None` — tworzy: `self._kamera = KameraRPi()`, `self._detektor = WykrywaczTwarzy()`, `self._serial = SerialInterface(port=port)`, `self._running = False`, `self._headless = False`, `self._czas_ostatniej_tx = [0.0]` (mutowalny ref dla heartbeat), `self._heartbeat: Optional[WatekHeartbeat] = None`.

- `uruchom(self) -> None` — otwiera serial (`self._serial.open()` w try/except — jesli fail: loguj warning, kontynuuj bez serial), uruchamia kamere (`self._kamera.start()`), tworzy i uruchamia heartbeat thread, ustawia `self._running = True`, wywoluje `self._petla_glowna()`. Po zakonczeniu petli: wywolaj `self.zatrzymaj()`.

- `_petla_glowna(self) -> None` — synchroniczna while self._running. Timestamp: `time.monotonic_ns() // 1_000_000` (monotonicznie rosnacy per Pitfall 3). Odczytaj klatke z kamery (`odczytaj()`). Jezeli None: sleep(0.01), continue. Wywolaj `self._detektor.wykryj(klatka, timestamp_ms)`. Wywolaj `self._detektor.wybierz_twarz(twarze)`. Jezeli bbox nie None: oblicz error przez `_oblicz_error(bbox, klatka.shape)`, wyslij `send_frame(mode=MODE_TRACK, error_x=ex, error_y=ey, face_size=fs)`. Jezeli bbox None: wyslij `send_frame(mode=MODE_SCAN, error_x=0, error_y=0, face_size=0)` per D-07. Po kazdym send_frame: update `self._czas_ostatniej_tx[0] = time.time()`. Rysuj HUD: `_rysuj_hud(klatka, bbox, error_x, error_y, tryb)`. try/except na calej iteracji — log error, continue.

- `_oblicz_error(self, bbox: Tuple[int, int, int, int], shape: Tuple[int, ...]) -> Tuple[int, int, int]` — per Research Code Examples sekcja. `x, y, bw, bh = bbox`, `h, w = shape[:2]`. `srodek_x = x + bw // 2`, `srodek_y = y + bh // 2`. `error_x = srodek_x - (w // 2)`, `error_y = srodek_y - (h // 2)`. Jezeli `w != 320`: skaluj `error_x = int(error_x * 160 / (w // 2))`, `error_y = int(error_y * 120 / (h // 2))`. Clamp: `error_x = max(-160, min(160, error_x))`, `error_y = max(-120, min(120, error_y))`. face_size: `area_ratio = (bw * bh) / (w * h)`, `face_size = int(area_ratio * 255)`, clamp 0-255. Return `(error_x, error_y, face_size)`.

- `_rysuj_hud(self, klatka: np.ndarray, bbox: Optional[Tuple[int,int,int,int]], error_x: int, error_y: int, tryb: str) -> None` — per D-03 wzorowany na legacy _rysuj_hud. Jezeli bbox: `cv2.rectangle(klatka, (x,y), (x+w,y+h), (0,255,0), 2)`. Nakresla crosshair w centrum klatki. Tekst: tryb (TRACK/SCAN), error X/Y, FPS (oblicz z `time.perf_counter()` delta). try/except na `cv2.imshow("ARIES-LITE pi_brain", klatka)`: jezeli cv2.error -> `self._headless = True`, loguj "Headless mode — brak wyswietlacza". `cv2.waitKey(1)`. Jezeli headless: skip imshow.

- `zatrzymaj(self) -> None` — **UWAGA: ta metoda moze byc wywolana z INNEGO WATKU niz petla glowna** (signal handler w `run_pi_brain.py` wywoluje `mozg.zatrzymaj()` z kontekstu signal handlera, podczas gdy `_petla_glowna()` biegnie w watku glownym). Dlatego `self._running = False` musi byc jedyna operacja zatrzymujaca petli — flaga `bool` jest thread-safe w CPython (GIL). Reszta cleanup uruchamia sie PO zakonczeniu petli (w `uruchom()` po powrocie z `_petla_glowna()`), LUB w `zatrzymaj()` jezeli petla juz nie dziala. Konkretnie: `self._running = False`. Stop heartbeat (`self._heartbeat.stop()`, join z timeout=1.0). Zamknij detektor (`self._detektor.zamknij()`). Zamknij serial (`self._serial.close()`). Zamknij kamere (`self._kamera.zatrzymaj()`). `cv2.destroyAllWindows()`. Loguj "MozgRPi zatrzymany". Calosc w try/except — log errors, nie przerywaj zamykania. Dodaj flage `self._zatrzymano = True` w `__init__` (init False) i sprawdzaj na poczatku `zatrzymaj()` — jezeli juz True, return natychmiast (guard przed podwojnym wywolaniem z signal handlera + z uruchom()).

```python
#!/usr/bin/env python3
"""Entry point ARIES-LITE v2.0 — pi_brain: MediaPipe wizja + SerialTX do Arduino."""

import signal
import logging
import sys

from src.vision.brain import MozgRPi

# Konfiguracja loggera
logging.basicConfig(
    level=logging.INFO,
    format="[%(levelname)s] %(name)s: %(message)s",
)
logger = logging.getLogger(__name__)


def main() -> None:
    """Uruchamia MozgRPi z obsluga sygnalow SIGINT/SIGTERM."""
    logger.info("ARIES-LITE v2.0 — pi_brain start")

    mozg = MozgRPi()

    def _obsluz_sygnal(sig: int, frame) -> None:
        """Handler SIGINT/SIGTERM — graceful shutdown.

        UWAGA: ten handler jest wywolywany z kontekstu glownego watku
        (Python signal handlers sa wykonywane w main thread), ale moze
        przerwac _petla_glowna() miedzy iteracjami. Dlatego mozg.zatrzymaj()
        ustawia self._running = False (thread-safe pod GIL) i ma guard
        _zatrzymano przeciw podwojnemu wywolaniu (signal handler + uruchom()).
        """
        logger.info(f"Sygnal {sig} odebrany — zatrzymuje system...")
        mozg.zatrzymaj()

    signal.signal(signal.SIGINT, _obsluz_sygnal)
    signal.signal(signal.SIGTERM, _obsluz_sygnal)

    try:
        mozg.uruchom()
    except Exception as e:
        logger.error(f"Blad krytyczny: {e}")
        mozg.zatrzymaj()
        sys.exit(1)

    logger.info("ARIES-LITE v2.0 — pi_brain zakonczony")


if __name__ == "__main__":
    main()
```
