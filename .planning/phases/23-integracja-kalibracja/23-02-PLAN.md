### 6. class MaszynaStanow (zalezy od ServoPID i HMI)
```cpp
class MaszynaStanow {
public:
    MaszynaStanow(ServoPID& serwa, HMI& hmi);
    void przetwarzaj_bajt(uint8_t bajt);  // parser
    void watchdog_krok();                  // millis() watchdog
    StanSystemu stan() const;
    unsigned long czas_ostatniej_ramki() const;  // dla watchdog w loop

private:
    ServoPID& _serwa;
    HMI& _hmi;
    StanSystemu _stan_systemu;
    uint8_t _ramka_buf[FRAME_SIZE];
    uint8_t _ramka_idx;
    StanParsera _stan_parsera;
    unsigned long _czas_ostatniej_ramki;

    void _przetworz_ramke();              // dawne dispatch_ramke
    void _przejdz_do(StanSystemu nowy);   // tranzycja + reset PID + buzzer
};
```

Konstruktor: `MaszynaStanow(ServoPID& s, HMI& h) : _serwa(s), _hmi(h), _stan_systemu(BEZCZYNNOSC), _ramka_idx(0), _stan_parsera(CZEKAJ_START), _czas_ostatniej_ramki(0) {}`

`przetwarzaj_bajt()`: identyczna logika parsera — CZEKAJ_START/CZYTAJ_PAYLOAD, checksum XOR, wywolanie _przetworz_ramke()

`_przetworz_ramke()`: identyczna logika jak obecny dispatch_ramke() — ekstrakcja pol, reset watchdog, _przejdz_do() jesli zmiana stanu. Cast `(StanSystemu)tryb` — dziala bo wartosci 0/1/2 zachowane.

`_przejdz_do(nowy)`: identyczna logika — reset PID przy SKANOWANIE i SLEDZENIE, buzzer_beep() przy SLEDZENIE, resetuj_czas_skanu przy SKANOWANIE

`watchdog_krok()`: przeniesiona logika z loop() — jesli stan != BEZCZYNNOSC && stan != SKANOWANIE i millis() - _czas_ostatniej_ramki > WATCHDOG_TIMEOUT_MS: _przejdz_do(SKANOWANIE)

### 9. loop()
```cpp
void loop() {
    while (Serial.available() > 0) {
        uint8_t bajt = (uint8_t)Serial.read();
        maszyna.przetwarzaj_bajt(bajt);
    }
    maszyna.watchdog_krok();
    serwa.pid_krok(maszyna.stan());
    hmi.lcd_krok(maszyna.stan(), serwa.kat_pan, serwa.kat_tilt,
                 serwa.ostatni_blad_x, serwa.ostatni_blad_y);
    hmi.przycisk_krok(maszyna.stan(), []() {
        // Lambda callback: abort TRACK -> SKANOWANIE
        // Nie mozna uzyc lambdy z capture w Arduino — uzyj globalnej funkcji
    });
}
```

POPRAWKA: Arduino avr-gcc nie wspiera lambdy z capture. Zamiast tego:
```cpp
// Globalna funkcja callback dla przycisku
void przycisk_abort_callback() {
    // Potrzebujemy dostepu do maszyna — ale jest global
    // Rozwiazanie: HMI::przycisk_krok() NIE uzywa callbacku, zamiast tego zwraca bool
}
```

LEPSZE rozwiazanie: `przycisk_krok()` zwraca `bool` (true = przycisk wcisniety, abort requested). Loop sprawdza i wywoluje przejscie:
```cpp
void loop() {
    // ... parser, watchdog, pid_krok ...
    hmi.lcd_krok(maszyna.stan(), serwa.kat_pan, serwa.kat_tilt,
                 serwa.ostatni_blad_x, serwa.ostatni_blad_y);
    if (hmi.przycisk_krok(maszyna.stan())) {
        // Abort TRACK — przejscie do SKANOWANIE wymaga MaszynaStanow
        // Dodaj publiczna metode: maszyna.wymus_skanowanie()
    }
}
```

Dodaj do MaszynaStanow: `void wymus_skanowanie() { _przejdz_do(SKANOWANIE); }` — uzywane przez przycisk abort.
