Stale modulowe:

- `TIMEOUT = 2.0`

Funkcja `wysylaj_petla(iface: SerialInterface, error_x: int, error_y: int, czas_s: float) -> None`:
- Petla: `koniec = time.monotonic() + czas_s`
- W petli: `iface.send_frame(mode=TRYB_TRACK, error_x=error_x, error_y=error_y, face_size=128)` + `time.sleep(OPOZNIENIE_TX)`
- KLUCZOWE: wysylanie w petli 20 Hz, nie jednorazowe — watchdog Arduino (500ms) resetuje stan per Pitfall 1

Funkcja `main() -> int`:
- Inicjalizacja: `iface = SerialInterface(port=PORT, timeout=TIMEOUT)` + `iface.open()` + `time.sleep(OPOZNIENIE_BOOT)` + `iface._ser.reset_input_buffer()`
- 4 kroki kalibracji, kazdy: print opis + wysylaj_petla() + input() pytanie PASS/FAIL:

Krok 1 — PAN prawo:
```

wynik_1 = input("Serwo pan poruszylo sie w PRAWO? [t/n]: ").strip().lower()
```

Krok 2 — PAN lewo:
- `error_x=-50`, oczekiwany ruch: LEWO

Krok 3 — TILT dol:
- `error_x=0, error_y=+30` (twarz ponizej centrum), oczekiwany ruch: TILT kompensuje DOL

Krok 4 — TILT gora:
- `error_x=0, error_y=-30`, oczekiwany ruch: TILT kompensuje GORA

Po 4 krokach: podsumowanie wynikow:
```python
wyniki = [("PAN prawo", wynik_1), ("PAN lewo", wynik_2), ("TILT dol", wynik_3), ("TILT gora", wynik_4)]
print("\n=== PODSUMOWANIE ===")
wszystkie_ok = True
for nazwa, wynik in wyniki:
    status = "PASS" if wynik == "t" else "FAIL"
    print(f"  {nazwa}: {status}")
    if wynik != "t":
        wszystkie_ok = False

if wszystkie_ok:
    print("\nKalibracja PASS — PAN_INVERT i TILT_INVERT poprawne.")
    return 0
else:
    print("\nKalibracja FAIL — zmien #define PAN_INVERT/TILT_INVERT w firmware i rekompiluj.")
    return 1
```

Finally block: `iface.close()`

Caly kod: komentarze po polsku, nazwy zmiennych po polsku per D-07/D-08. Wyjatki: SerialInterface, MODE_TRACK, time.sleep — techniczne per D-08.
