# Plan 03-01: Cleanup Dependencies, Exports & Project Structure

<objective>
Remove unused dependencies, add proper package exports, and clean up orphaned directories from old tooling. This completes v1.5.0 stabilization by leaving a clean project structure.
</objective>

## Tasks

<task id="1" name="Remove imutils and add __all__ exports">

<read_first>
- requirements.txt
- src/__init__.py
- src/camera.py (VideoStream class)
- src/vision.py (HybridVision class)
- src/tracker.py (TrackerMachine class)
- src/hardware.py (PanTiltSystem class)
- src/config.py (module)
</read_first>

<action>
1. In `requirements.txt`, delete line `imutils==0.5.4`

2. Replace contents of `src/__init__.py` with:
```python
# Eksporty publiczne modulu src
__all__ = [
    "VideoStream",
    "HybridVision",
    "TrackerMachine",
    "PanTiltSystem",
    "config",
]
```
</action>

<acceptance_criteria>
- `grep "imutils" requirements.txt` returns no matches
- `grep "__all__" src/__init__.py` returns a match
- `grep "VideoStream" src/__init__.py` returns a match
- `grep "HybridVision" src/__init__.py` returns a match
- `grep "TrackerMachine" src/__init__.py` returns a match
- `grep "PanTiltSystem" src/__init__.py` returns a match
- `grep "config" src/__init__.py` returns a match
</acceptance_criteria>

</task>
