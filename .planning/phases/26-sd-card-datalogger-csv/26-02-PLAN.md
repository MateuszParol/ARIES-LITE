  <action>
Flash the firmware onto Uno R4 WiFi using arduino-cli:

```bash
arduino-cli compile --fqbn arduino:renesas_uno:unor4wifi src/arduino/aries_controller/aries_controller.ino
arduino-cli upload --fqbn arduino:renesas_uno:unor4wifi --port /dev/ttyACM0 src/arduino/aries_controller/aries_controller.ino
```

If upload fails with port busy or permission error, try:
1. `ls /dev/ttyACM*` to find correct port
2. Ensure no Serial Monitor is open
3. Retry upload

After successful upload, wait 3 seconds for board reset, then capture Serial output for ~5 seconds to verify bootup messages:
```bash
timeout 5 cat /dev/ttyACM0 2>/dev/null || echo "Serial capture done"
```

Expected Serial output should contain either:
- `[SD] Karta SD zainicjalizowana pomyslnie.` + `[BENCH] SD write: XXX us` (SD card present)
- `SD fail` + `[SD] OSTRZEZENIE: Karta SD niedostepna!` (no SD card)

Both are valid — confirms DataLogger init runs without hanging.
