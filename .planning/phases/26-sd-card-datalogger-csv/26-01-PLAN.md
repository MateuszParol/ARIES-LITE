**2. Add HMI::sd_ostrzezenie() method (inside class HMI, after rtc_ostrzezenie(), before `private:` section):**
Pattern matches `rtc_ostrzezenie()` from Phase 25 but shorter (SD less critical than RTC). Per Claude's Discretion — consistent alarm style.
```cpp
    // Ostrzezenie SD — karta SD niedostepna (HYBRID: ostrzezenie + kontynuacja)
    // LCD: "SD: FAIL" przez ~1.5s + krotki alarm buzzer
    void sd_ostrzezenie() {
        _lcd.clear();
        _lcd.setCursor(0, 0);
        _lcd.print("SD: FAIL        ");
        _lcd.setCursor(0, 1);
        _lcd.print("Brak karty SD   ");
        tone(BUZZER_PIN, 1500, 200);  // 1.5kHz, 200ms — krotszy niz RTC fail
        delay(1500);
    }
```

**3. Add class DataLogger (after class ZegarRTC, before global instances section):**

Full class with:
- Constructor: `DataLogger(ZegarRTC& zegar)` with initializer list setting `_zegar(zegar)`, `_sd_ok(false)`, `_licznik_klatek(0)`, `_wpisy_od_flush(0)`, `_ostatni_dzien(0)`
- `bool inicjalizuj()` — calls `SD.begin(SD_CS_PIN)`. If fail: prints `F("SD fail")` to Serial, sets `_sd_ok = false`, returns false. If success: sets `_sd_ok = true`. Guard: if `!_zegar.czy_dostepny()` then disable logging (no RTC = no timestamps = useless, per Claude's Discretion). Calls `_otworz_plik_dnia()`. Runs benchmark (LOG-05): `micros()` around `_plik.print(F("TEST,0,0,0,0,0,0,0\n"))`, prints result to Serial as `[BENCH] SD write: XXX us`, then seeks back to overwrite test line or truncates (simplest: just leave test line — it has header before it). Returns true.
- `void krok(StanSystemu stan, float pan, float tilt, int16_t bx, int16_t by, uint8_t fs, uint16_t latency_ms)` — guard: if `!_sd_ok` return. If `stan != SLEDZENIE`: reset `_licznik_klatek = 0`, return (per D-08). Increment `_licznik_klatek`, if `< 10` return (per D-06, log every 10th frame). Reset counter to 0. Call `_sprawdz_rotacje()`. Call `_zapisz_csv(stan, pan, tilt, bx, by, fs, latency_ms)`.
- `bool czy_dostepne() const` — returns `_sd_ok` (for HMI display)

Private members:
- `ZegarRTC& _zegar`
- `File _plik`
- `bool _sd_ok`
- `uint8_t _licznik_klatek`
- `uint8_t _wpisy_od_flush`
- `uint8_t _ostatni_dzien`

Private methods:
- `void _otworz_plik_dnia()` — guard `!_zegar.czy_dostepny()` return. Get `DateTime teraz = _zegar.odczytaj_czas()`. Build filename with `snprintf(nazwa, sizeof(nazwa), "L%02d%02d%02d.CSV", (int)(teraz.year() % 100), (int)teraz.month(), (int)teraz.day())` into `char nazwa[13]`. If `_plik` is open: `_plik.flush(); _plik.close();`. Open `_plik = SD.open(nazwa, FILE_WRITE)`. If `_plik && _plik.size() == 0`: write header `_plik.println(F("timestamp,stan,pan,tilt,error_x,error_y,face_size,latency_ms"))` then `_plik.flush()` (per D-05). Set `_ostatni_dzien = teraz.day()`.
- `void _zapisz_csv(StanSystemu stan, float pan, float tilt, int16_t bx, int16_t by, uint8_t fs, uint16_t latency_ms)` — guard `!_sd_ok || !_plik` return. Get `DateTime teraz = _zegar.odczytaj_czas()`. Build line with `snprintf(linia, sizeof(linia), "%lu,%d,%d,%d,%d,%d,%d,%d", (unsigned long)teraz.unixtime(), (int)stan, (int)pan, (int)tilt, (int)bx, (int)by, (int)fs, (int)latency_ms)` into `char linia[64]`. Write `_plik.println(linia)`. Increment `_wpisy_od_flush`, if `>= 50` then `_plik.flush()` and reset to 0 (per D-07, LOG-03).
- `void _sprawdz_rotacje()` — guard `!_zegar.czy_dostepny()` return. Get `DateTime teraz = _zegar.odczytaj_czas()`. If `teraz.day() != _ostatni_dzien` then call `_otworz_plik_dnia()` (per LOG-02).
