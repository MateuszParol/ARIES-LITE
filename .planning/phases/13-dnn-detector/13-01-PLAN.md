3. **DetekcjaTwarzy.wykryj()** — zamien CALE cialo metody (per D-03, D-05, D-06, D-07/D-08):
   - Inkrementuj `self._klatka_licznik`
   - Co DNN_SKIP_EVERY klatek (`self._klatka_licznik % DNN_SKIP_EVERY == 0`):
     - Pobierz h, w z klatka.shape[:2]
     - Utworz blob: `cv2.dnn.blobFromImage(klatka, 1.0, (300, 300), (104.0, 177.0, 123.0), swapRB=False)`
       UWAGA: swapRB=False bo model trenowany na BGR, a OpenCV dostarcza BGR. NIE uzywaj swapRB=True.
     - Forward pass: `self._net.setInput(blob)` + `detections = self._net.forward()`
     - Iteruj po detections.shape[2], szukaj pierwszej detekcji z confidence > DNN_CONFIDENCE_THRESHOLD
     - Konwertuj znormalizowane bbox (0-1) do pikseli: x1*w, y1*h, (x2-x1)*w, (y2-y1)*h
     - Zapisz jako self._ostatni_bbox (x, y, w, h) lub None jesli brak detekcji
   - Streak filter (kazde wywolanie, nie tylko forward pass):
     - Jesli self._ostatni_bbox is None: self._streak = 0, return None
     - Inaczej: self._streak += 1
     - Jesli self._streak >= STREAK_REQUIRED: return self._ostatni_bbox
     - Inaczej: return None

4. **DetekcjaTwarzy.resetuj_streak()** — zachowaj bez zmian (per D-05). NIE resetuj _ostatni_bbox — DNN moze ponownie wykryc te sama twarz.

5. **Docstring klasy** — zmien z "Detekcja twarzy HAAR z filtrem streak" na "Detekcja twarzy DNN (res10_300x300) z filtrem streak."
